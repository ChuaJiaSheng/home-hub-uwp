Interaction Task
- Speech Interaction (Text-to-Speech)
  - AI Chat Page: Type in the textbox and click "Send." If nothing is typed in the textbox, a formatted speech will be played.

- Touch Interaction (Drag and Drop)
  - Home Page — Clock Pivot: Able to drag and drop the clock around the whole area (dynamically changing with window size).
  - Note: Some gestures might conflict with the Swipe Interaction. Slowing down your movement speed will help avoid this issue.

- Gesture Interaction (Swipe)
  - All Pages (except Settings Page): Swipe up to return to the previous page, swipe down to go to the next page. (Home Page → Sketching Page → AI Chat → Home Page)

- Keyboard Interaction
  - AI Chat Page: Press "Enter" to act the same as clicking the "Send" button. Press "Escape" to clear all the text in the textbox.

- Inking Interaction
  - Sketching Page: Able to draw on the canvas (dynamically changing with window size).
  - Note: Some gestures might conflict with the Swipe Interaction. Slowing down your drawing speed will help avoid this issue.

Self-Proposed App
- Settings App: Inspired by the minimalist yet elegant design of the Windows Phone link settings.
  - The page is designed to be simple, yet easy to understand and navigate.
  - The current theme is light, but users will have the ability to switch to dark mode.
  - Language settings allow users from different nationalities to easily understand the app.
